Privacy

Privacy

The short version: this site collects nothing about you. It has no forms, no accounts, no cookies and no analytics, and its pages load no resources from other websites.

What is collected

  • By this site: nothing.
  • By the host: the site is served by GitHub Pages. As the hosting provider, GitHub may process visitors' IP addresses and request details in server logs, as described in GitHub's privacy statement. This site does not receive that data.
  • If you open an issue on GitHub to send a correction, that is governed by GitHub's terms and privacy statement, and the issue is public.

RSS

The RSS feed is a plain file. Your feed reader fetches it; this site does not track who subscribes.

If this changes

If a newsletter or analytics is added later, this page will be updated first and will say what is collected, by whom, and how to opt out.

How these tools work

Each tool is a small model that runs in your browser. It gives the same result every time for the same steps. The model is simpler than a real app. Each page lists what it leaves out.

If JavaScript is off, each page still shows a plain explanation and a table of examples. Not sure where to begin? Pick a reading path for your level.

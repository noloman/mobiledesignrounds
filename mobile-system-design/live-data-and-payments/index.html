Live data and payments case studies

These cases are about data that changes while the user watches, and about actions that must happen only once. You design streams of updates, holds that end on server time, and payments that are safe to retry. The hard parts are order, gaps, time and money. The stock ticker shows an app that is always online. The booking app shows how to stay safe when the result of a payment is not clear.
